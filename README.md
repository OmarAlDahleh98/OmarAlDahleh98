<details>
<summary><b>🔍 My working principles</b></summary>

- Start with the decision the analysis needs to support.
- Keep the data model clean, consistent, and validated.
- Use the simplest visual that answers the business question clearly.
- Separate descriptive metrics from actionable insights.
- Prioritize accuracy, readability, and business context over visual noise.
