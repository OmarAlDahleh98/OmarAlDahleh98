## 📐 My Analytics Workflow

<div align="center">

**Business Question** → **Data Preparation** → **Validation** → **Analysis** → **Dashboard** → **Actionable Insight**

</div>

<details>
<summary><b>🔍 How I approach a data problem</b></summary>

<br/>

**01 — Understand**  
Define the business question, KPI, target audience, and decision that needs support.

**02 — Prepare**  
Clean data, handle missing values, validate types, transform fields, and build a reliable model.

**03 — Analyze**  
Use SQL, Python, DAX, and descriptive analysis to identify patterns, trends, and performance gaps.

**04 — Visualize**  
Build focused dashboards with clear hierarchy, useful filters, meaningful KPIs, and business context.

**05 — Communicate**  
Turn the analysis into concise insights that help stakeholders understand what happened and what to do next.

</details>
